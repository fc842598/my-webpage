# 紫微十二宫记忆训练场：站内复原说明

这里保留了从桌面完整源码包迁入的核心 React 源码，并适配为阅天AI静态站可直接发布的独立功能页。

## 站内文件

- `page.tsx`：17 项训练、三关难度、计分与进度保存。
- `styles.css`：训练场原始样式及电脑、平板、手机响应式适配。
- `entry.tsx`：静态页面挂载入口。
- 发布页：`pages/ziwei-palace-training.html`。
- 发布资源：`css/ziwei-palace-training.css`、`js/ziwei-palace-training.js`。

训练记录保存在访问者自己的浏览器 `localStorage` 中，不依赖数据库，也不会读取会员、支付或命盘资料。发布时使用已经打包好的静态 JS，不需要在线安装依赖或运行 Node 服务。

## 当前版本包含

- 12 格标准紫微命盘布局。
- 地支格位、时辰、生肖、经络、月份、方位、五行、阴阳、六冲、三合等训练。
- 十二宫序、宫位含义、对宫、三方四正训练。
- 《天纪02》身体体型盘训练。
- 十天干顺序及天干阴阳五行训练。
- 三关难度、答题速度升级、查看全部答案、即时对错提示与本机进度保存。
