## 2. 《易经推命起大运法》里能直接落成规则的部分

### 2.1 起运主轴

书里明确写出：

- `男命女命同`
- `先由先天卦之元堂定起一岁`
- `阳爻交变九年`
- `阴爻交变六年`

并给了明确例子：

- `先天卦：风水涣`
- `后天卦：地风升`
- `元堂在九二位`
- `一岁至九岁，由元堂初变`
- `故此先天卦共管四十五年`
- `后天卦共管四十二年`

### 2.2 流年推进的阴阳年变法

书里还明确写出流年推进法则：

- `凡阳爻遇阳年不变`
- `阳爻逢阴年则变`
- `阴爻不分阴阳年皆变`

这不是解释性语言，而是可执行规则。

### 2.3 起月卦 / 小限 / 月卦推进

已看到的页里还有：

- `阳卦从子月起`
- `阴卦从五月生`
- 多个月卦例子
- `余流年小限求法，依此类推即可`

这说明书里并不只给“流年卦”，还给了按月推进的白盒思路。

## 3. 这段与 300 条真值池的直接对照结果

### 3.1 已直接对上的地方

真值池 `300` 条样本的流年总长度分布为：

- `75`: `26`
- `81`: `65`
- `87`: `72`
- `93`: `82`
- `99`: `49`
- `105`: `6`

这组结果和书里的 `阳九阴六` 主轴高度一致。

也就是说：

- 天纪软件的流年总长度不是 UI 随机截断
- 它确实服从“按爻阴阳分配年数”的体系
- 书里这条主轴可以直接作为当前实现的白盒依据

### 3.2 已被我们样本反推先行验证的地方

书中的下面两条，和现有真值反推结论一致：

- `元堂定起一岁`
- `阳年/阴年变法`

也就是说，当前样本反推不是瞎猜，而是已经踩到书面规则主轴上了。

### 3.3 这段还不能直接解决的地方

这段虽然足够解释：

- 流年总长度
- 流年推进
- 元堂在大运/流年里的作用

但目前还没有在已检查页里看到它对白盒写出：

- `早子 / 夜子` 的入口分裂
- `未 / 亥` 这种“同四柱但先天/后链分叉”的软件级 civil-slot 规则
- 当前剩余 `16 / 300` 先天卦残留的完整入口表

所以这段很适合用来校正“起运与流年”，但还不够直接解决全部入口边界。

## 4. 《铁版神数之排列法》里能直接落成规则的部分

从当前已看的页，已能确定这段至少包含：

### 4.1 纳甲/纳支框架

书里给了：

- 上卦 / 下卦 的纳甲纳支表
- 阴卦纳支 / 阳卦纳干支的对照思路
- 由内外卦推配支、再查配数表的做法

这说明“铁版神数之排列法”不是纯占例，而是带表格的编码体系。

### 4.2 世应公式

书里明确写出：

- `安世与应爻`
- `一世与一应`
- 每组各有固定公式

并且举了按卦型计算世应、再取应交/世交的例子。

### 4.3 内卦 / 外卦 / 互卦

书里明确强调：

- 内外卦互变很重要
- 去掉初爻与上爻，取中间四爻求互卦
- 内外卦、互卦在六亲/铁版推法里都不能忽略

换句话说，书里给的是一套“卦内部结构运算”框架，而不是只给结论。

这段最有可能帮助我们补的是：

- `先天卦 -> 元堂 -> 后天卦` 之间的白盒结构

### 5.2 它当前还不能替代样本反推

但就当前已看的页来说，这一段还不能直接替代真值池，原因有三：

1. 它讲的是规则框架和例法，不是完整软件规格表  
2. 还没看到把所有 civil-slot 家族完整列成决策表

所以，这段适合做：

- 白盒确认

- 解释为什么某些分支存在

不适合做：

- 现在立刻抛弃样本池，从书直接重写整套实现

## 6. 当前方向判断

结论很明确：

### 6.1 继续样本反推仍然是主线

原因：

- 我们已经把问题压到很窄
- 当前主残留不是“大面积黑箱”
- 真值池已经把大量软件行为锁死

### 6.2 原书现在可以正式进入“白盒支撑线”

最合理的用法不是替代，而是并行：

1. 用书里 `易经推命起大运法` 校正：
   - 元堂起岁

   - 纳甲/纳支
   - 世应
   - 互卦
