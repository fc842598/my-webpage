## 2. 后天卦的普通规则

《天机道》P52 直接给了普通换卦法：

- `先天卦求出，元堂又定位，则以元堂之爻，阳爻变阴爻，阴爻变阳爻，再移外卦入内，内卦出外，看成何卦，此为天旋地转更革之象，就是后天卦。`

来源：

- [《天机道》PDF P52](https://www.vr-d.com/pdf-file/%E5%A4%A9%E6%9C%BA%E9%81%93-%E5%80%AA%E6%B5%B7%E5%8E%A6%E7%AE%80%E4%BD%93-%E5%80%AA%E6%B5%B7%E5%8E%A6.pdf)

可直接落成实现：

1. 输入：
   - `xiantian.upper`
   - `xiantian.lower`
   - `yuanTangLine`
2. 先在 `yuanTangLine` 上变爻
3. 得到“变后卦”
4. 再做一次 `swapOuterInner`
   - 外卦入内
   - 内卦出外
5. 输出即为普通后天卦

### 书中明示例子

同页给出的例子：

- 先天卦：`风水涣`
- 元堂：`九二`
- 后天卦：`地风升`

也就是：

- `风水涣` 不是直接换成别的
- 而是先在元堂位变爻
- 再做内外卦交换
- 最终得到 `地风升`

这条例子非常重要，因为它说明普通后天卦算法并不是黑箱。

## 3. 三至尊卦的真正边界

《天机道》P52-P54 说得很明确：

- 只有三至尊卦特殊：
  - `坎为水`
  - `水雷屯`
  - `水山蹇`
- 特殊原因：
  - `九五爻为阳君`
  - `上六阴爻为阴之主`
  - `乃至尊至极之爻，不可轻易变更`

来源：

- [《天机道》PDF P52-P54](https://www.vr-d.com/pdf-file/%E5%A4%A9%E6%9C%BA%E9%81%93-%E5%80%AA%E6%B5%B7%E5%8E%A6%E7%AE%80%E4%BD%93-%E5%80%AA%E6%B5%B7%E5%8E%A6.pdf)

这段有一个实现上非常关键的边界：

- 特例只针对 `九五` 和 `上六`
- 不是说“只要是三至尊卦，全部都走特殊换卦”

也就是说：

- 如果三至尊卦的元堂落在 `1 / 2 / 3 / 4`
- 仍然走普通规则：
  - 变元堂爻
  - 再内外卦交换

这点必须写死，否则会误把 `水山蹇 -> 地水师` 这类普通变卦错判成“三至尊特例”。

## 4. 三至尊卦的特例映射

书里把三至尊卦分成两组特例：

- `九五`
- `上六`

并按：

- `阳令 = 冬至后到夏至前（十一月到四月）`
- `阴令 = 夏至后到冬至前（五月到十月）`

区分不同后天卦。

## 6. 后天卦的最小实现规格

只针对后天卦，最小伪代码应是：

```text
输入：
  xiantian
  yuanTangLine
  monthBranch

1. 先判断 monthBranch 属于阳令还是阴令
2. 如果 xiantian 不是三至尊卦：
   - 走普通规则
3. 如果 xiantian 是三至尊卦，但 yuanTangLine 不在 5/6：
   - 仍走普通规则
4. 如果 xiantian 是三至尊卦，且 yuanTangLine=5：
   - 走“九五特例映射”
5. 如果 xiantian 是三至尊卦，且 yuanTangLine=6：
   - 走“上六特例映射”
6. 输出后天卦
```

## 8. 这里哪些还不能只靠书面材料定死

单靠当前公开书面页，仍然不能完全定死的，是“元堂到底怎么定位”。

原因不是书里没提元堂，而是：

- 书里更强调“先有元堂，再换后天卦”
- 但当前网站真正错得最厉害的地方，很可能就在元堂定位
- 同一个普通后天卦公式，只要元堂错一爻，后天卦就会整体错掉

所以修后天卦时应优先分层检查：

1. `先天卦` 是否对
2. `yuanTangLine` 是否对
3. `computeHouTian()` 是否对

如果：

- 普通卦错
- 三至尊卦也错

通常首先怀疑 `yuanTangLine`，不要第一时间怀疑“后天卦公式”。

## 9. 对当前项目的直接建议

如果下一步只修后天卦，不碰年卦，顺序应是：

1. 保持 `四柱 -> 先天卦` 不动
2. 把后天卦实现拆成独立校验：
   - 输入四柱
   - 输出先天卦、元堂、后天卦
3. 先拿普通卦样本校普通规则
4. 再拿三至尊卦样本校九五/上六特例
5. 最后再回头修年卦

换句话说：

- 后天卦现在不是“完全没有规则”
- 书面规则已经足够写出 `computeHouTian()`
- 真正还要继续反推的，主要是 `元堂`

## 10. 本文用途

这份文档只解决一件事：

- 把“后天卦该怎么写”从黑箱，收束成可以直接编码的规则表
