  → 本站提炼「明枪可防、化刑为勇」，给庙旺得地的正面用法与硬碰硬的防守。
- 陀罗：阴金化气为忌=暗箭、拖延纠缠慢性、永在禄存后一宫，正面耐力深耕。
  → 本站给「硬死线+拆小步+外部节奏」破解拖延的可操作框架。
- 火星：阳火化气为耗、闪电爆发短促，贪狼+火星=火贪横发。
  → 本站讲爆发力的调度与横发后落袋，防三分钟热度。
- 铃星：阴火闷烧、外冷内热、积压后爆发，贪狼+铃星=铃贪。
  → 本站强调定期情绪出口、给积压找释放阀。
- 天巫：只行寅申巳亥四马地、主升迁继承祖荫玄学、佐曜逢吉才灵。
  → 本站定位「只在动地上灵的传承星」，讲清逢煞无力。
- 天厨：主俸禄口福、与贪狼爱吃会做、与巨门化禄以口生财、入官禄利餐饮食品。
  → 本站把「口福」转成餐饮食品营养等职业路径。
- 解神：主化解解围、乐观共情、利调解助人岗。
  → 本站定位「逢凶化吉的缓冲星」，讲清它解的是局面不是免灾。
