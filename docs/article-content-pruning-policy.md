# 阅天AI文章整理标准

更新：2026-09-08。目的：让读者能找到值得读的内容，不以文章数量或删除数量作为成绩。

## 先看价值，再看怎么处理

全文读完后，每项0至4分，共20分。0分是缺失或严重错误，2分是部分做到，4分是清楚、具体、可靠。评分只辅助编辑判断，不作为自动删除或发布门槛。

| 项目 | 要回答的问题 |
| --- | --- |
| 读者需要 | 是否解决真实、明确的问题，而不是为关键词硬凑场景？ |
| 独立价值 | 是否值得单独占一页，还是一段FAQ就能说完、旧文已经讲完？ |
| 准确可信 | 前提、星曜和本命/运限是否分清？是否凭空保证、把模型错误归咎于用户？ |
| 信息实质 | 有没有明确答案、条件、解释或适当例子，而不是换词重复标题？ |
| 自然可读 | 普通读者能否理解？是否生硬拼接、绕圈、英文夹着未翻译中文？ |

16至20分优先保留；10至15分做必要修订；0至9分进入全文复核、合并或删除候选。不能仅凭标题、字数、相似度或某个词给全站自动打分。短而有用的文章可以保留，长而空泛的文章可以删除。

## SEO与用户资产单独保护

- 已观察到搜索展示/排名的URL，按用户要求保护，不改正文、标题、描述、发布时间，不删除。中英文各自判定。
- 查询GSC精确URL，并注明时间范围和搜索类型。没有数据不能声称没有收录；已收录也不能直接等同有排名。
- 核对GA4完整文章路径导出。只有事件、没有浏览量也算有活动线索；内部测试尚未排除，不能称真实客户。
- 报告缺行仅表示本期未记录。新文章、尚未覆盖的日期、排名未查或数据不完整，先保留待查。
- 有访问、外链、重要站内用途的文章，优先保留或合并。GSC外链报告0不证明全网无外链。

## 四种处理结果

1. 保留：有独立价值，或属于排名保护页面。
2. 改写：问题有价值，但解释或表达差。Humanizer仅用于编辑，不替代事实判断，不编造客户经历。
3. 合并：多个页面回答同一个问题，保留有价值段落进入真正对应的页面；有同等替代内容才设置301，不一律跳首页。
4. 删除：全文缺少独立价值或有严重模板错误，已核查排名、访问和引用，且无值得保留内容。移除页面及公开引用，返回真实404/410，Git保留可恢复版本。
