# 2026-04-18 许大师升级（前端）

## 本次目标

- 把 许大师从“报错页”改成可用的角色对话入口。
- 让页面直接看见许大师到底读了哪些命盘层级。
- 把用户能感知到的状态改成更像产品，而不是技术提示。

## 实际完成

- 角色卡新增了正式会话 / 临时会话状态徽章。
- 角色卡新增了“已读哪些命盘层”的可视标签：
  - 基础命盘
  - 整体批命
  - 身宫批命
  - 大运结果
  - 流年结果
- 会话初始化和发送成功后，都会同步刷新：
  - Memory A 摘要预览
  - Memory A 来源标签
  - 会话模式状态
- 命盘切换、Memory A 失效、初始化失败时，页面会同步重置这些展示。

## 现在的用户体验

- 即使 Supabase 还没建聊天表，只要后端是新版本，许大师也能先走临时会话。
- 用户能直接看见：当前是不是临时会话，许大师读没读到整体批命 / 大运 / 流年。
- 这套体验更接近同行产品常见做法：人设明确、起手问题明显、上下文可见、少技术词。
