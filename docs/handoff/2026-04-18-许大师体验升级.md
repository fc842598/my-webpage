# 2026-04-18 许大师体验升级（前端）

## 1. 本次目标

- 把 许大师 面板从“技术壳子”改成更像可直接开问的命理对话区。
- 后端缺聊天表时，不再给用户原始报错。
- 给用户一个明确的“命盘已读 / 对话已整理 / 可刷新命盘记忆”的使用体验。

## 2. 实际完成

- 角色卡新增了：
  - `重读命盘` 按钮
  - 命盘摘要预览区
  - 四个快捷提问入口
- 徽章文案从技术词改成用户可懂的状态：
  - `命盘待读取 / 命盘已读入 / 命盘待刷新`
  - `对话未整理 / 对话已整理 vN`
- `ai-chat.js` 改成：
  - `send` 也支持非 JSON / 缺表错误的友好处理
  - 命盘切换后自动重置 session
  - 可手动触发 `POST /api/ai/chat/session` 强制重读 Memory A
  - 预热请求改成 `OPTIONS /api/ai/run`，不再制造 `__ping__` 垃圾会话
