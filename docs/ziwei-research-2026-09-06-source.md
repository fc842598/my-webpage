## 二、同行观点框架（仅借主题与骨架）→ 本站差异化切入

### 辅煞曜（8）
- 禄存：同行普遍区分禄存=稳定存量/守财，化禄=流动机缘/增量；禄存永被擎羊陀罗夹。
  → 本站强化「存量vs增量」「财库压舱石」的现实理财类比，讲清禄存最喜会天马/化禄。
- 天马：同行指出只在寅申巳亥四马地、为中性加速器，会禄为禄马、会紫府为扶舆、逢空为折足。
  → 本站用「加速器不是财」「驮禄还是驮煞」做决策框架。
- 禄马交驰：同行讲同宫/对拱/三方会、动中生财、发异乡财、属自力。
  → 本站强调「不是躺赚、必须本人奔走」，补空马破格与防守。
- 孤辰寡宿：同行分形孤（外）/心孤（内）、按年支取、清冷星系最显、主晚婚。
  → 本站破除「注定孤身」误区，给晚婚与主动表达的可操作建议。
- 华盖：同行讲孤高、艺术玄学、专精、易脱离现实。
  → 本站定位「向内钻的钥匙」，强调给才华接现实出口。
- 天刑：同行讲法律/自律/刀光/医药缘、天刑喜天喜。
  → 本站提炼「规则之刃」，区分用在专业（权威）还是情绪（硬碰）。
- 龙池凤阁：同行讲才艺审美仪表、力量温和为佐曜。
  → 本站定位「专业感微调器」，强调锦上添花、依附主星。
- 天哭天虚：同行讲情绪低落、空亡虚耗、多成对。
  → 本站定位「情绪漏气点」，给用小成果重建掌控的具体路径。

### 十二宫（3，补齐剩余宫位）
- 兄弟宫：同行延伸到同辈/合伙人，且为现金库相关。
  → 本站定义「平辈生态窗口」，给能不能合伙的判断步骤。
- 夫妻宫：同行强调既看配偶也看自身关系模式、对宫官禄牵动。
  → 本站做「双向镜」框架，破「见煞就断离」误区。
- 奴仆宫：同行讲宫干飞化（化禄入命有助/化忌入命被拖累）、紫微在奴仆下属骄、先助后反。
  → 本站区分兄弟（平级）与奴仆（众人下属），讲择人用人。

### 格局（7）
- 三大框架：同行指出人人必居机月同梁/杀破狼/府相朝垣之一，无高下。
  → 本站类比「操作系统」，强调选对赛道比努力重要。
- 机月同梁：「作吏人」、公职大企业参谋、逢昌曲佳、见煞破格。
- 杀破狼：三星固定三方、开创动荡、波浪式人生、须攻守转换。
- 府相朝垣：府库+印、稳重管理、逢空露库、防过度保守。
- 日月反背：日月失辉主劳碌白手、非定死差命、晚成靠专业。
  → 本站与日月庙旺贵格做对照（缺光vs自带光）。

- 石中隐玉：巨门子午守命会禄、大器晚成、口才研究立身。

### 进阶看盘（6）
- 叠宫：本命为体/大限环境/流年触发，三层叠定主题、飞化定怎么演。
- 伏吟反吟：大限命叠本命=伏吟（向内、旧题重演），走对宫=反吟（外冲）。
- 来因宫：钦天飞星概念，生年天干所在宫为四化总源头；与三合派区分不混淆。

### 主星（2，补齐14主星最后两颗）
- 天府：南斗主、阳土、财库田宅主，是库不是源，逢禄实、逢空漏，课题是适度进取。
- 廉贞：阴火、化气为囚、次桃花，弹性最大、近朱赤近墨黑，关键在情绪与边界管理。

### 四化（3）
- 化忌一定不好吗：本质为内收/卡点/执着/修炼课题，庙旺化忌可辛苦有成。
- 禄存/化禄/化权三种得财：守得住/进得来/争得到，最佳为禄权相会+禄存锁。
- 禄忌同宫/双化忌：得中有失、能量纠结，解法是降杠杆、分批、先落袋。

### 大限流年（3）
- 大限命宫找法与十年主轴：五行局起运、顺逆行、以大限命宫重排十二宫。
- 流年吉凶：流年命宫重排+流年四化+流月应期，三层合参。
- 换大限交接年为何动荡：新旧并置、换挡期，先立后破。
