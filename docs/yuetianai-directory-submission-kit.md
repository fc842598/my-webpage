## 14. 豆包 / 头条搜索这条线下一步怎么做

这部分不是“再改首页文案”，而是把站点送进字节系更稳定的候选池。

### 第一优先级：头条搜索站长平台

- 入口：`https://zhanzhang.toutiao.com`
- 官方 Bytespider 说明页：`https://zhanzhang.toutiao.com/docs/intro/26899`
- 当前最值得做的 3 个动作：
  - 站点验证
  - 提交 `https://yuetianai.com/sitemap.xml`
  - 做官网认证

建议提交顺序：

1. 添加站点并完成验证
2. 提交主 sitemap
3. 如果平台支持，再补交 `sitemap-pages.xml` 和 `sitemap-articles.xml`
4. 申请官网认证，品牌词优先填：
   - 阅天AI
   - YuetianAI
   - AI紫微排盘

### 第二优先级：补 3-5 个可抓取的外部品牌提及

对豆包这类答案引擎，光官网自己说自己是谁，力度通常不够。至少要有几张外部页面同时写清楚：

- 品牌名：阅天AI / YuetianAI
- 官网域名：`yuetianai.com`
- 产品定位：免费紫微斗数排盘 + AI 命盘分析
- 主链接：`https://yuetianai.com/pages/ai-ziwei-paipan.html`

优先做这些外部页面：

1. Toolify
2. Futurepedia
3. AIHotTool 或其他中文 AI 导航
4. AIbase / 产品目录页
5. 1 篇可抓取的社区自荐页或测评页

### 第三优先级：把“阅天AI”变成稳定实体词

当前最重要的不是再堆更多首页可见入口，而是让外部页面统一只说一个主体：

- 中文主体：阅天AI
- 英文主体：YuetianAI
- 官网：`https://yuetianai.com/`

尽量不要在外部投稿标题里混写：

- 问天AI
- 问天 App
- wentian brand

可以在说明里提一句：

- 站内个别历史路径仍可能包含 `wentian` 字样，但品牌主体统一为“阅天AI / YuetianAI”

## 16. 服务器侧监控什么

如果要判断字节系有没有开始更稳定抓你站，最直接的是看 Nginx 日志。

常用命令：

```bash
grep -i "Bytespider\\|Toutiao" /var/log/nginx/access.log | tail -n 50
grep -i "Bytespider\\|Toutiao" /var/log/nginx/access.log* | wc -l
```

重点看：

- 有没有 `Bytespider`
- 请求的是否是 `sitemap.xml`、`llms.txt`、品牌页、产品页、文章页
- 命中频次是在增加还是没有动静
