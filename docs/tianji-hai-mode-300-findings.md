## 1. 基础池先把 `亥时` 压成了 3 种模式

在 300 条基础真值里，原生 `亥时` 共有 `36` 条。

按“天纪真值后天卦”反推，这 36 条可以先分成 3 类：

- `16` 条：当前网站已有逻辑直接命中
- `18` 条：只要把 `亥` 保持 `lower-six` 的位置，但元堂改走 `阳池`，当前后天卦公式就能命中
- `2` 条：连改阳池都不够，还要另一支后天卦公式

所以，`亥时` 在天纪里绝对不是单一规则。

---

## 2. 先把“当前代码已解释到的”部分剥开

这 36 条里，当前网站已经解释到 2 类女性口袋：

- `female-hai-ordinary-line-matrix`
- `female-late-lower-six-trigram-147-yang`

把这两类剥开后，基础池里剩下 `29` 条默认 `亥时` 盘，都落在：

- `normalRuleTag = lower-six-default-yin`

基础池在这 `29` 条上的结构结论已经很整齐：

- `3` 个阳爻：`9/9` 都走 `yin-pool`
- `1 / 2 / 4` 个阳爻：`18/18` 都走 `yang-pool`
- `5` 个阳爻：`2/2` 都落入第三种 `alt-transform`

换成“先天期总年数”看，也是同一件事：

- `45 年`：都走 `yin-pool`
- `39 / 42 / 48 年`：都走 `yang-pool`
- `51 年`：都走 `alt-transform`

这已经说明：对“原生 `亥时` + 默认 lower-six-default-yin”这一口袋，分叉主轴不像月令，更像：

- `先天卦阳爻个数`
  或
- `先天期总年数`

## 3. 先补 `0 / 5 / 6` 阳爻边界，默认 `亥时` 被完整分区

为了补齐基础池里没出现过的边界，这次额外抓了 `16` 条原生 `亥时` 真值：

- `5 阳爻 / 51 年`：`8` 条
- `0 阳爻 / 36 年`：`4` 条
- `6 阳爻 / 54 年`：`4` 条

补样后：

- 基础池原生 `亥时`：`36`
- 边界补样：`16`
- 合计：`52`

其中再剥掉女性现有特例后，默认 `亥时` 盘总数变成：

- `40` 条 `lower-six-default-yin`

这 `40` 条现在已经被完整压成一个结构分区：

- `0 / 3 / 6` 个阳爻：全部走 `yin-pool`
- `1 / 2 / 4` 个阳爻：全部走 `yang-pool`
- `5` 个阳爻：全部走 `alt-transform`

对应到先天期总年数，也是一一对应：

- `36 / 45 / 54 年`：全部走 `yin-pool`
- `39 / 42 / 48 年`：全部走 `yang-pool`
- `51 年`：全部走 `alt-transform`

也就是说，默认 `亥时` 现在已经不是“看起来像这样”，而是被 `40` 条真值完整压成：

```text
原生亥时 + lower-six-default-yin:
0/3/6 阳爻 -> 阴池
1/2/4 阳爻 -> 阳池
5 阳爻     -> 第三公式
```

## 4. `5 阳爻` 特殊口袋从 2 条补到了 7 条

过去基础池只有 `2` 条 `5 阳爻 / 51 年` 的残留盘。  
现在默认 `亥时` 的 `5 阳爻` 特殊盘已经变成 `7` 条。

这 7 条全都不满足：

- 当前 `亥时` 阴池 + 当前公式
- 强制 `亥时` 阳池 + 当前公式

但它们出现了一个非常整齐的共同候选：

- 全部都能命中 `line = 5`
- 全部都能命中 `flipThenSwap`
- 全部都能映射到 `卯` 这一支的 `upper-six-default-yang`

所以这 7 条当前最干净的共同解释仍然是：

```text
原生亥时 + 5阳爻:
视作虚拟“卯”分支
取 line = 5
仍走 flipThenSwap
```

从纯结果上看，它也等价于：

- `swapThenFlip(line = 2)`
- `flipYingThenSwap(line = 2)`

但就“结构最像时段映射”的解释来说，当前最强候选仍然是：

- `虚拟卯支 + line 5 + flipThenSwap`

## 5. 女性 `乾为天` 的残留不是随机点，而是完整的“半年分流”

在上一轮边界补样后，实验规则还能剩下 `1` 条残留：

- 女命
- `亥时`
- `乾为天`

因此又专门补了两轮定向样本：

- `10` 条女命 `亥时 + 乾为天`
- 再补 `6` 条，把月支一整圈打满

现在女命 `亥时 + 乾为天` 已经覆盖到了完整 12 月支：

- `丑`
- `寅`
- `卯`
- `辰`
- `巳`
- `午`
- `未`
- `申`
- `酉`
- `戌`
- `亥`
- `子`

结论非常整齐：

### `丑 / 寅 / 卯 / 辰 / 巳 / 午`

全部是：

- 后天卦：`风天小畜`
- 命中方式：沿用 `female-hai-ordinary-line-matrix` 的 `line = 1`
- 模式：可视为 `yin-half`

### `未 / 申 / 酉 / 戌 / 亥 / 子`

全部是：

- 后天卦：`天泽履`
- 命中方式：切到强制 `yang-pool` 的 `line = 6`
- 模式：可视为 `yang-half`

所以这最后一个女性残留现在也不再是黑箱，而是完整压成：

```text
女命 + 亥时 + 乾为天:
丑寅卯辰巳午 -> 风天小畜
未申酉戌亥子 -> 天泽履
```

这条分流很像“半年切半”，不是随机月令噪声。

## 6. `未 / 亥` 同四柱分叉没有被推翻

在 300 条基础池里，`未 / 亥` 同四柱、同先天卦的配对共有 `20` 对。

这 20 对现在仍然成立，而且没有被后续补样推翻：

- `未` 端：全部符合“折成亥柱，但元堂仍按原始未时段取”
- `亥` 端：会落入下面 3 种模式之一
  - `yin-pool`
  - `yang-pool`
  - `alt-transform`

这 `20` 对里，`亥` 端的实际分布仍然是：

- `12` 对：`yin-pool`
- `8` 对：`yang-pool`
- `0` 对：`alt-transform`

所以 `未 / 亥` 同四柱分叉本身已经不是主黑箱；真正的主黑箱一直都是原生 `亥时` 的后链切分。
