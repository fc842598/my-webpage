# 命宫总批 AI 调试文档（基础版）

## 任务范围
- 只处理「命宫格局」这一个卡片。
- 输入重点只看命宫本宫与命宫三方四正。
- 允许参考生年四化，但不要扩写到婚姻、财运、健康等独立模块。

## 输入结构
- `命宫标题`：前端当前卡片标题，通常是「主星组合 + 坐命」。
- `命宫`：本宫主星、辅星、杂曜、四化。
- `官禄宫 / 财帛宫 / 迁移宫`：命宫三方四正。
- `命盘格局`：五行局等基础标签。
- `生年四化`：全盘四化摘要。

## 分析顺序
1. 先点明命宫主星的核心气质和行事方式。
2. 再看三方四正如何托举或牵制命宫。
3. 明确指出最关键的结构性优势。
4. 明确指出最需要注意的一条风险。

## 输出要求
- `title`：必须沿用输入里的命宫标题，不要自造新标题。
- `summary`：80 到 160 字，必须引用命宫主星，且至少提到一个三方四正宫位。
- `risk`：1 句，最多 50 字。
- `basis`：开发调试字段，简要说明本次判断主要依据，必须点名命宫和至少一个三方四正宫位。

## 禁止事项
- 不要杜撰命盘里没有出现的星曜、宫位、四化。
- 不要把三方四正写成泛泛而谈的套话。
- 不要输出 markdown 标题、列表、代码块。
- 不要把 `summary` 写成玄而不实的鸡汤文。

## 调试目标
- 让开发人员能直接看到：输入上下文、调试文档、system prompt、user prompt、模型返回。
- 当前阶段优先可调试、可复核，不优先追求最终包装。
