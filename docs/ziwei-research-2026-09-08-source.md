## 二、同行观点框架（仅借主题与骨架）→ 本站差异化切入

### 格局命例（8）
- 七杀朝斗/仰斗：七杀在寅申子午守命、禄存科权拱、化煞为权，主开创权威。
  → 本站严格区分朝斗仰斗成格条件，落「开创者的班底与节奏管理」，破见七杀即贵。
- 财荫夹印：天相被天府（财）天梁（荫）相夹，主稳中有贵、受人扶持。
  → 本站专门与刑忌夹印对照，讲「被什么夹住决定天相是稳还是压」。
- 刑忌夹印：天相被天梁化忌（或擎羊）相夹，主责任压力与官非风险。
  → 本站与财荫夹印成对讲，给「重流程留痕、把压力熬成专业」的解法，并区分刑囚夹印旧文。
- 善荫朝纲：天机天梁在辰戌、会吉，主善荫谋略、逢凶化吉。
  → 本站定位「谋定后动的清贵组合」，讲清辰优戌劣与逢煞打折。
- 天乙拱命：天魁天钺分守命宫三方或夹命，主一生多贵人。
  → 本站区分「左贵右贵」与贵人类型，落「先有被帮的价值才有贵人」。
- 文星拱命：文昌文曲三方拱照，主聪慧文采考试。
  → 本站讲「才华要扎进一门专业兑现」，破有才无成。
- 辅弼拱主：左辅右弼同会或夹紫微，主助力副手。
  → 本站核心「成大事靠班底」，区分辅弼（助力）与魁钺（机会型贵人）。
- 凶格合集（马落空亡等）：天马遇空劫、禄存遇空，主奔忙落空。
  → 本站把「动而空」转成「动前先确认落点」，给空曜的止损与备选框架。

### 辅煞曜（5）
- 六煞排布规律：羊陀永夹禄存、火铃随年支安、空劫永远对宫。
  → 本站用「排布是固定的、吉凶是组合的」破煞星恐惧，给安星逻辑图。
- 地空地劫 vs 截空旬空：两组空曜来源不同、空法不同（漏散 vs 中断/空耗）。
  → 本站专门做四空曜对比，纠正混用。
- 六吉会聚：左右昌曲魁钺禄存会齐的成格条件。
  → 本站讲「吉星也要看落宫与主星」，破见吉就套好格。
- 制煞为用：煞星庙旺、得禄权、被主星驾驭时反成动力。
  → 本站给「庙旺+引动+出口」三条件，讲化煞为用而非灭煞。
- 暗曜杂曜群：天刑天月天伤天使阴煞等小星的含义与权重。
  → 本站定位「辅证不主断」，明确小星只在与主星四化呼应时才计权重。

### 四化细读（4）
- 四化两两同宫：禄权/禄科/权科/权忌/科忌五种双象组合。
  → 本站核心「单象不成物、双象才成形」，逐组合给基调与落星修正。
- 自化权自化科：宫干化回本宫的内耗，好胜硬撑与好面子。
  → 本站区分生年/飞宫/自化三层，给「把内循环转成可交付」的解法，避开旧文自化禄忌。
- 禄随忌走、忌入忌出：禄是入口忌是出口、能量卡进或推出。

- 化忌坐本宫 vs 忌冲对宫：坐是内在打结、冲是对面受波及。
  → 本站严格分坐冲与轻重，纠正「见对宫有忌就判本宫坏」。
