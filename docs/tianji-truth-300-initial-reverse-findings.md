## 1. 子时必须拆成两类，且会打穿整条链

不是只有时柱不同，而是：
- `四柱`
- `先天卦`
- `后天卦`
- `流年卦序列`

都会跟着变化。

## 3. 流年总长度只落 6 个值

当前 `300` 条样本里，`liunian` 长度只出现：
- `75`
- `81`
- `87`
- `93`
- `99`
- `105`

分布：
- `93`: `82`
- `87`: `72`
- `81`: `65`
- `99`: `49`
- `75`: `26`
- `105`: `6`

这个现象非常重要：
- 长度不是随机截止
- 只按 `6` 年为步长变化
- 高度符合“阴爻 6 年 / 阳爻 9 年”体系的总和结果

当前推断：
- 终止年龄大概率来自 `先天卦 + 后天卦` 两段总爻期的自然和
- 不是 UI 随便截到 `81 / 87 / 93`

这条结论目前仍属于“强推断”，但已被 `300` 条长度分布显著支持。

## 4. 某些先天卦 / 后天卦组合会稳定落在固定总长度

样本里高频组合已经显示出长度稳定性，例如：

- `山地剥 -> 坤为地`：`75`
- `地山谦 -> 坤为地`：`75`
- `风地观 -> 地山谦`：`81`
- `地风升 -> 山地剥`：`81`
- `风雷益 -> 地风升`：`87`
- `雷风恒 -> 山雷颐`：`87`
- `水天需 -> 风水涣`：`93`
- `山风蛊 -> 巽为风`：`93`
- `天水讼 -> 地天泰`：`93`
- `巽为风 -> 风天小畜`：`99`

含义：
- 总长度不只是看出生日期，而是已经和 `先天/后天` 这组结构绑定。
- 后续反推时，可以反过来用长度约束 `元堂 / 后天卦 / 年卦推进`。

## 5. 下一轮反推建议

现在最合理的顺序是：

1. 先拆“天纪四柱入口”
- 特别是 `early-zi / night-zi`
- 以及立春前后四柱切换

2. 再拆“先天卦映射”
- 用全天矩阵组按日期、性别、时段分层对比

3. 再拆“先天卦 -> 后天卦”
- 把总长度一起纳入约束

4. 最后拆“流年推进”
- 已经有 300 条完整年表，不需要再先补量

也就是说，当前阶段不该继续盲目加样本，而该开始真正做规则归纳。
