正文草稿：
单身上班族想买第一间属于自己的房子，家人最常说的一句话是“一个人扛得起吗”。这句话听着像反对，其实是在问风险。田宅宫能帮你看清自己想要什么样的居住环境和安全感，但它不能替你回答月供还不还得起。把命盘的提示和现金条件分开核对，家人的担心才能一条条被回应。

### 家人的担心，先翻成具体数字
“扛不起”是个笼统说法，要先拆成几个能算的问题：每个月固定收入多少，房贷月供占多少，扣掉月供还剩多少生活余量，万一收入中断能撑几个月。把这些数字摆出来，家人反对的是哪一段，才看得清楚。田宅宫给的是倾向，真正决定房子的是这些可核对的现金条件，不能用“命里有房”之类的话跳过计算。

### 月供占比的分步判断

1. 先算清每月税后稳定收入，不把奖金、年终这类不固定的钱算进基数。
2. 列出当前每月固定支出，包括房租、家用、保险和必要的生活开销。
3. 用试算工具算出目标房子的月供，再除以稳定收入，得出占比。
4. 把占比和扣完月供后的生活余量一起看，单看一个百分比容易误判。
5. 若占比偏高或余量太紧，先调低总价或延长准备期，不硬签。

### 田宅宫提示和现金条件分开
田宅宫的星曜组合，反映你对采光、空间、稳定感的偏好，适合在能负担的范围内帮你筛选房子，而不是用来证明“这间一定能买”。若盘面显示你重视安定，但现金条件过不了关，就如实承认现在还不到时候，先把储蓄和收入做厚。把两件事混在一起，最容易做出后悔的决定。

### 排盘使用顺序

1. 先固定出生时间和盘面，确认田宅宫的位置和星曜组合。
2. 把田宅宫的居住偏好单独记下，先不和贷款数字混看。
3. 再用真实收入和支出做月供占比与生活余量试算。
4. 现金条件通过后，才回到田宅宫在可负担范围内挑房。
5. 结论保留条件，不把命盘倾向包装成购房结果的保证。

### 为什么预备金不能并入头期款
头期款付出去就变成房子，短期拿不回来；紧急预备金要保持灵活，随时能取用。两者用途不同，混在一起，等于把安全垫也锁进了房产。真正的居住安稳，既包括房子本身，也包括遇到突发情况时不必被迫借钱或卖房。

1. 先统计买房后每月的固定开销，把月供、管理费、保险都算进去。
2. 按收入稳定程度定目标，受雇者通常先以三到六个月开销为基准。
3. 若收入波动大、行业不稳或单身无第二收入，把月数往上加。
4. 单独保留这笔钱，不挪去装修、家电或提前还贷。
5. 头期款和预备金都到位前，不把购房时间提前。

### 田宅宫怎样提示缓冲
田宅宫的星曜若偏稳，往往更重视长期安定，反而提醒你要留足缓冲；若带煞或空劫，则更要留意突发的维修、变动和现金缺口。但这些是提示，不是具体金额，月数仍要按真实开销计算。把盘面提示和实际数字并排，缓冲留多少才踏实。

### 排盘使用顺序

1. 先固定盘面，确认田宅宫星曜是偏稳还是带变动。
2. 把“需要缓冲”的提示记下，再去算买房后的真实开销。
3. 按收入稳定性确定预备金的目标月数。
4. 头期款和预备金分账户管理，不互相挪用。
5. 留足缓冲后再推进购房，结论保留条件。

正文草稿：
很多房贷采用浮动利率，眼前月供轻松，不代表以后轻松。利率一旦上行，同样的本金会带来更高的月供，原本刚好的余量会被一点点吃掉。田宅宫讲居住安定，而真正的安定，要经得起利率变化的压力测试，而不是只按今天的利率做打算。

### 为什么不能只按当前利率算
当前利率是一个时点，还款却要持续很多年。只按最低利率算月供，等于假设未来一直宽松，一旦利率回升，月供差额就要从生活余量里补。把升息后的数字也算一遍，才知道这套房在不同环境下是否都扛得住。

### 升息压力测试的分步判断

1. 先记下当前利率下的月供和扣完月供后的生活余量。
2. 用试算工具分别假设利率上调几个百分点，算出对应月供。
3. 比较升息前后的月供差额，看余量能否吸收。
4. 若升到某一档余量就转负，把这一档当作明确的风险线。
5. 风险线太紧时，调低总价、提高首付或考虑固定方案。

### 田宅宫与风险线
田宅宫若偏稳，提示你更看重长期可承受，正适合用压力测试把风险线提前找出来；若星曜偏冲动，则更要警惕只看眼前低利率就出手。盘面给的是性格倾向，具体能不能扛，仍由升息后的真实数字决定。

### 排盘使用顺序

1. 先固定盘面和田宅宫，确认自己对风险的倾向。
2. 再算当前利率下的月供与生活余量。
3. 逐档上调利率做压力测试，标出余量转负的风险线。
4. 据风险线决定总价、首付和利率方案。
5. 结论保留条件，不把今天的低利率当成永久。
