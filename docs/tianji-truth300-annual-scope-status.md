### 2. 天纪 line 列对应的是“每年实际作用爻”的倒序显示

对 300 条真值池逐年回放后，可以把天纪右侧 `line` 列压成稳定规则：

1. 先按现有起运主链，求出该年真正作用的爻位 `appliedLineNum`
2. 再按天纪显示口径做倒序映射：
   - `1 -> 5`
   - `2 -> 4`
   - `3 -> 3`
   - `4 -> 2`
   - `5 -> 1`
   - `6 -> 0`

等价写法：

`tianjiLineNum = appliedLineNum === 6 ? 0 : 6 - appliedLineNum`

因此现在生成结果里应区分两类字段：
- `governingLineNum`：当前所处爻段的主爻（旧口径）
- `tianjiLineNum`：天纪右侧逐年显示的编号（新口径）
