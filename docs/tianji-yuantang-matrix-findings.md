## 4. 采样时遇到的边界现象

这轮实操里有 3 个值得记下来的现象：

1. 32 位 `天纪.exe` 用 64 位 `pywinauto` 会持续报 warning，但控件读写仍可用。

2. 某些候选盘虽然界面 `comboSelected` 已切到目标时段，但算出来的时柱地支和目标时段不一致。
   - 这类样本我没有纳入最终矩阵。
   - 最终保留的 13 条都已经核过“界面时段”和“时柱地支”一致。

3. 更早年代的候选盘在这条自动化链路下不够稳定。
   - 我尝试过 `1900/1912` 一类年份做 `female early-zi`
   - 但返回结果不稳定或直接空白
   - 所以最终把新增样本收敛到 `1960` 这一批稳定可读的盘

## 5. 对下一步的直接建议

现在最合理的下一步不是继续补更多随机盘，而是做两件更窄的事：

1. 只针对这 13 条新增样本，建立一个“元堂待复核清单”
   - 每条样本逐条尝试从 GUI 结构、截图、课程图式、现有规则反推 `yuanTangLine`

2. 把现有 `11` 条旧真值样本和这 `13` 条新样本合并成一份“元堂专用黄金集”
   - 只比较：
     - 四柱
     - 先天卦
     - 元堂爻
     - 后天卦

这样后面如果继续修 `getYuanTangDetail(...)`，就不会再和年卦问题混在一起。
