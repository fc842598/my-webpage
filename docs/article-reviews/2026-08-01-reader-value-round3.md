## 逐篇终审

### 01 PASS

副业转主业是成熟且高风险的真实决策。正文依次检查可带走的收费能力、外部客户、原单位资源、大限流年和现金储备；两个例子分别覆盖“财帛化科、天钺、迁移客户”与“官禄化权但订单依赖原公司”。行动明确到二十笔订单来源、半年复购回款和十二个月储备，边界是不以一次收入或好时段替代商业验证。

### 02 PASS

销售还是专业顾问对应真实职业选择。文章先分市场成交与专业收费，再按星曜落财帛或官禄判断收入或岗位，最后用收入结构验证；两个例子分别是太阳贪狼的市场财与文曲化科、魁钺的专业财。行动包括转化率、复购、案例、定价和平台依赖测试，没有把单星固定成职业。

### 03 PASS

订单多但现金紧是经营者会直接搜索的问题。判断从贪狼的业务量进入，再查财帛化忌的折扣、退单、垫资和账期，最后检查朋友宫分账；两个例子覆盖“贪狼化忌吞毛利”与“朋友巨门化忌、空劫引发合作争议”。读者可立即拆分订单、应收、毛利和可用现金，且不把营业额当利润。

### 04 PASS

相亲进入婚前共同财务协商，换题后价值明显高于泛泛的感情合不合。文章按夫妻与福德、双方财帛、田宅、书面规则推进；两个例子分别处理夫妻化权下的共同账户与大额双签，以及廉贞天府、财帛化禄、田宅火星下的产权和房屋风险。行动具体到收入、债务、首付、产权、月供和退出方案，命盘不代替法律所有权。

### 05 PASS

伴侣适不适合合伙是婚恋与经营交叉的真实问题。文章先确认夫妻与福德的关系基础，再看朋友宫合作质量、双方财帛承受和小项目试验；两个例子清楚区分“夫妻化权、朋友天机天马有助但须限额”与“夫妻稳定、朋友巨门化忌空劫导致分账争议”。工资、股权、分红、借款和退出均有现实动作。

### 06 PASS

异地恋能否进入婚姻有明确人群和决策成本。判断把缘分入口、外地平台、夫妻福德承接及身宫牵动依次分开；两个例子覆盖红鸾天喜配福德天机化忌，以及迁移紫微破军辅弼但夫妻承接普通。试住、城市、职业损失、探亲和退路都可执行，不以桃花或外地吉象保证婚姻。

### 07 PASS

“机会出现但结果没落实”是高频流年困惑，第三轮已消除抽象机器式框架。正文按流年落宫、固定四化、大限背景、现实里程碑读取；两个例子分别是官禄化科从初试走到书面录用，以及父母化禄从介绍客户走到合同、验收和到账。每一步都有负责人和日期，边界明确为好消息不等于录用或收入。

### 08 PASS

换工作、搬家、感情同年变化属于真实复杂场景。文章先用日期找最早改变资源或承诺的事件，再用流年宫位和三方四正验证因果，最后回夫妻福德区分旧问题与阶段摩擦；两个例子分别由官禄化权和迁移紫微破军辅弼启动。一次只做一个不可逆决定的动作直接可用。

### 09 PASS

关系宫流年究竟应在谁身上，是学习和咨询中都会遇到的实质问题。文章按关系角色、星曜四化、双方互动、本人代价和三方四正展开；两个例子分别是夫妻宫原有化权带来家庭重新分工，以及朋友宫六煞令本人补款收尾。读者会分栏记录对方事件、共同变化和本人承担，不再机械推给别人。

### 10 PASS

父母出首付后谁做主是高金额、高冲突的现实决策。文章先区分父母宫化禄资源与化权主导，再分田宅资产、财帛偿付和法律文件；两个例子覆盖本人可独立还贷时的赠与安排，以及父母承担大部分资金时的借款或共同持有。四栏会议“谁付款、谁负债、谁登记、谁决定”可直接执行，也与第 04 篇的婚前整体财务协商保持不同主线。

### 11 PASS

工作稳定却长期疲惫是广泛真实痛点。文章先看官禄的专业或权责，再看身宫占比与福德恢复，最后做岗位实验；两个例子分别是官禄化权、身宫官禄、福德天机化忌，以及官禄有科无权、福德七杀造成管理角色错位。四周记录会议、临时任务和休息，避免直接劝辞或硬撑。

### 12 PASS

外地机会好但住不稳对应迁移、定居和买房决策。正文先验证真实岗位与团队，再用六至十二个月租住测试，单独检查田宅和现金，最后设定扎根门槛；两个例子覆盖迁移紫微破军辅弼与迁移紫微缺辅、田宅火星。行动包括合同、租住、安全、保险、储备与支持网络，不以迁移吉强迫买房。

### 13 PASS

房贷约束下换工作具有清晰搜索意图与现实风险。文章按换工原因、新平台质量、现金空窗、大限流年排期推进；两个例子分别是迁移机会明确但储备仅三个月，以及官禄科权启动且储备覆盖十二个月。书面录用、空窗储备和回撤方案构成硬边界，避免把时机当担保。

### 14 PASS

孩子本地还是外地读书是家庭真实决策，且强调用盘伦理。文章先限定父母盘只能提出问题，再回孩子命宫、迁移和官禄，最后用学校条件和一学期复盘验证；两个例子分别处理孩子迁移紫微破军辅弼、官禄化科，以及父母盘空宫焦虑但孩子昌曲学习线可用。课程、费用、住宿、安全和求助条件都可核对。

### 15 PASS

科权禄同宫还是分散在三方四正，虽属进阶术语，却直接服务升职、权责和收入判断。文章先拆三种功能，再比较集中优势与传递链，最后找最弱承接；两个例子分别是官禄科权禄集中但组织资金不等于个人收入，以及命科、官权、财禄形成能力到收入的链。验证落到资格、授权、预算、成交和现金。

### 16 PASS

化科化忌并见如何处理，是常见的组合判断。文章先定位可保留的专业优势，再找化忌的重复卡点，同宫补流程、分宫分线治理；两个例子分别是财帛文曲化科伴随范围和账期问题，以及官禄化科、财帛化忌造成评价好但收入受阻。修改次数、预付款、毛利和回款都是具体动作，不做吉凶相减。

### 17 PASS

“被认可却没人付费”对应个人品牌和专业变现的真实痛点。文章按被记住、有效咨询和真实付款三层验证；两个例子均以命宫化科会昌曲为基础，一例主题分散无服务，一例主题集中且连续有订金复购。三十天记录与三道检查能指导收窄主题、修改服务或扩大渠道，不承诺命宫化科必然成名。

### 18 PASS

第一轮唯一 FAIL 已实质修复。当前问题是经营者或主管能赚钱、掌预算却无法休息，判断先分财帛化权的掌财角色和钱的归属，再看禄、福德化忌、身宫与恢复成本；两个例子分别是有经营收益的老板和只有责任、没有利润归属的主管。净收入、授权、睡眠和离线时间给出扩张、加代理人、重谈补偿或缩减业务的依据。

### 19 PASS

亲属合伙与外部合作的风险区分具有直接商业价值。文章先按对象区分兄弟宫与朋友宫，再看化忌及巨门羊陀等结构、三方承接、资金和权限；两个例子分别处理亲属采购分红边界与外部伙伴报价责任冲突。关系图、资金图和权限图可执行，不把一次失败扩大成人际皆差。

### 20 PASS

### 21 PASS

### 22 PASS

### 23 PASS

### 24 PASS

擎羊是否必然事故是高频恐惧型问题。文章按性质、庙陷、落宫和叠煞分层；两个例子分别是擎羊入庙落官禄会权而无火铃，以及擎羊落陷疾厄会陀铃，并说明同组落夫妻时改看冲突。医疗交给正规检查，工作用复核，关系用暂停边界，没有职业越界或绝对恐吓。

吉星煞星能否抵消是基础且广泛的读盘问题。文章先定宫位和主星，再分别保留资源、风险、庙陷及会照，最后转成三栏行动；两个例子分别是朋友宫获客资源与巨门化忌分账风险并存，以及疾厄天府禄存与落陷陀罗并存。合同、账户、复核和专业健康判断均有明确边界。
