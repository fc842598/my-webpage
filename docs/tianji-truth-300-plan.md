# 天纪真值 300 条采样方案

目标不是机械把 50 放大到 300，而是让后续反推 `四柱 -> 先天卦 -> 后天卦 -> 流年卦` 时，变量能拆开看。

## 总结构

- 现有 50 条：已经完成，作为第一层基础样本
  - `A`: 1991-06-15 全天 13 时段 × 男女
  - `B`: 1991 立春窗口 `夜子 / 早子`
  - `C`: 1991 四季固定 `亥时`
  - `D`: 1991 连续日固定 `亥时`
- 新增 250 条：分两类
  - `234` 条：9 个锚点日期的全天矩阵
  - `16` 条：4 个年份的立春窗口 `夜子 / 早子` 边界

合计：
- `50 + 250 = 300`

## 为什么这样设计

### 1. 全天矩阵最值钱

对同一天：
- 固定日期
- 固定历法
- 固定地点条件（当前桌面版天纪无地点输入）
- 只换 `性别`
- 只换 `13 个 civil slots`

这样最容易看出：
- 子时如何拆 `夜子 / 早子`
- 时段如何影响时柱
- 性别如何影响先天卦 / 后天卦 / 流年推进

### 2. 锚点日期优先选“已知关键盘”

新增 9 个全天矩阵锚点：
- `1966-06-25`
- `1969-03-26`
- `1971-10-06`
- `1984-04-08`
- `1991-02-16`
- `1996-01-02`
- `1999-12-26`
- `2021-03-28`
- `1930-02-18`

理由：
- 包含之前已经核过的 verified 样本
- 包含用户明确指出过的问题盘 `1999-12-26`
- 包含历史边界盘 `1930-02-18`
- 能覆盖不同年代、不同月令、不同已知口袋

### 3. 立春边界必须单独做

新增 `16` 条边界样本：
- 年份：`1930 / 1966 / 1996 / 2021`
- 时段：`2月3日 23:30 (night-zi)`、`2月4日 00:30 (early-zi)`
- 性别：男女都做

这个组专门用来看：
- 年柱什么时候切
- `夜子 / 早子` 如何跨日
- 立春窗口是否影响年卦起点和先后天结构

## 批量执行策略

不是一次跑 300，而是断点续跑：

- 基础 50：已完成
- 新增 250：按 `25` 条一批跑
- 当前脚本会自动：
  - 读取现有 `50`
  - 跳过已采样 id
  - 只补下一批 pending
  - 输出累计结果

## 文件

- 主脚本：
  - `tmp/collect_tianji_truth_300_real.py`
- 基础样本：
  - `tmp/tianji-truth-50.json`
- 300 条累计输出：
  - `tmp/tianji-truth-300.json`
- 300 条累计报告：
  - `docs/tianji-truth-300-report.md`

## 当前阶段建议

先不要直接开跑 300。

先做：
1. 用新脚本 `--dry-run` 确认 pending 计数正确
2. 先采新增第一批 `25`
3. 肉眼检查其中至少 `2~4` 条带流年样本
4. 再继续下一批

这样后续反推时，样本结构才可控，不会只是堆数量。
