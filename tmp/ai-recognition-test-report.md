### 具体问题清单

#### 1. 农历中文表述（严重）
**影响范围**: 所有使用农历的用户

**失败案例**:
- "农历七月初三" → 无法提取月日
- "冬月十五" → "冬月"（十一月）未识别
- "腊月"、"正月"等传统月份名称均未支持

**技术原因**: 当前解析逻辑仅支持阿拉伯数字月份（1-12），未建立农历中文映射表

**修复优先级**: 🔴 高

---

#### 2. 模糊时间处理（中等）
**影响范围**: 不确定出生时间的用户

**失败案例**:
- "大概是晚上饭点时候" → "饭点"无映射
- "夏天" → 无法确定月份（6-8月？）
- "过年的时候" → 春节日期每年不同

**建议方案**: 
- 对模糊描述给出提示："检测到您不确定时间，是否使用时辰推算功能？"
- 引导用户切换到手动填写模式

**修复优先级**: 🟡 中

---

#### 3. 亲属称谓性别识别（轻微）
**影响范围**: 帮家人查询的用户

**失败案例**:
- "儿子" → 应推断为male
- "老公" → 应推断为male
- "女儿" → 已能识别为female（因含"女"字）

**修复方案**: 增加亲属称谓映射表
```javascript
const kinshipGenderMap = {
  '儿子': 'male', '女儿': 'female',
  '老公': 'male', '老婆': 'female',
  '丈夫': 'male', '妻子': 'female',
  '爸爸': 'male', '妈妈': 'female'
};
```

**修复优先级**: 🟢 低

---

#### 4. 传统时辰转换（轻微）
**影响范围**: 使用十二时辰表述的用户

**失败案例**:
- "亥时" → 应转换为21:00-23:00
- "子时" → 23:00-01:00（需区分早子/夜子）

**现有代码**: 已有`shichenLabel(hour)`函数做反向转换，但缺少正向解析

**修复方案**: 增加时辰→小时的映射
```javascript
const shichenToHour = {

```

**修复优先级**: 🟢 低
