# 天纪真值采样 - 单条真实样本采集操作指南

## 📋 当前状态

- ✅ 天纪软件已启动（进程运行中）
- ⏳ 等待您在天纪中输入数据并排盘
- ⏳ 等待您提供排盘结果截图/文字

---

## 🔧 操作步骤（请按顺序执行）

### 第1步：在天纪软件中手动输入

打开已经运行的天纪软件，输入以下信息：

```
公历: 1991-02-16
时间: 22:00 (或选择亥时)
性别: 男
地点: 上海
```

然后点击**排盘按钮**，等待结果显示。

---

### 第2步：截图保存

将天纪界面显示的完整排盘结果**截图**，保存到：

```
C:\Users\1\Desktop\家里用的图标\tmp\tianji-manual-screenshot.png
```

---

### 第3步：记录排盘结果

打开文件：`tmp/tianji-manual-input.txt`

将天纪界面显示的四柱、卦象等信息**复制或手抄**到该文件中。

**格式示例：**
```
四柱: 辛未年 庚寅月 丙子日 己亥时
先天卦: 坎为水
后天卦: 水雷屯
流年: 1岁-辛未, 2岁-壬申, 3岁-癸酉, 4岁-甲戌, 5岁-乙亥, 6岁-丙子, 7岁-丁丑, 8岁-戊寅, 9岁-己卯, 10岁-庚辰
```

**注意：** 以上只是示例格式，请替换为天纪实际显示的数据！

---

### 第4步：运行整理脚本

完成上述1-3步后，在终端运行：

```bash
cd "C:\Users\1\Desktop\家里用的图标"
python tmp\collect-one-real-tianji-sample.py
```

脚本会：
1. 读取您填写的 `tianji-manual-input.txt`
2. 自动整理成标准JSON格式
3. 保存到 `tmp/tianji-truth-one-real.json`
4. 生成报告到 `docs/tianji-truth-one-real-report.md`

---

## 📁 最终输出文件

完成后会生成以下文件：

1. **`tmp/tianji-truth-one-real.json`** - 标准格式的1条真实样本
2. **`docs/tianji-truth-one-real-report.md`** - 详细的采集报告
3. **`tmp/tianji-manual-screenshot.png`** - 天纪界面截图（需您提供）
4. **`tmp/tianji-manual-input.txt`** - 人工记录的排盘结果（需您填写）
