The Three-Step Flying-Palace Method for Beginners

The three-step method breaks palace-stem flights into three: first set Tai Ji (which palace you speak from), then find that palace stem transformations, finally read the cause and effect of the landing palaces. Following these three steps keeps flying stars orderly.

Zi Wei Dou Shu2026-10-07

Flying stars are like sending letters from one palace to others; first know where you stand, then to whom the letter goes, finally what happens when received.

What This Question Is Really Asking

Some learn flying stars without setting Tai Ji and lose direction; others see transformations without the landing and miss cause and effect; the three-step method treats both problems.

The Underlying Logic

Step one set Tai Ji: determine the starting palace, knowing where you speak from.

Step two find stem transformations: see which star that palace stem transforms to Lu Quan Ke Ji.

Step three read landings: which palace each transformation flies to, setting cause-effect direction.

Lu is cause and Ji is effect; the landing palace stars and environment set the concrete form.

A Step-by-Step Way to Read It

  1. First settle the matter to trace, choose the starting palace and set Tai Ji
  2. Look up the starting palace stem against the transformation table
  3. Find which star that stem transforms to Lu, Quan, Ke, Ji
  4. Read which palace the transformed stars sit in, the landings
  5. First read the Lu landing as cause, then the Ji landing as effect
  6. Combine the landing palace stars and trines to set the concrete direction

Three Common Mistakes

Mistake 1: Flying without setting Tai Ji and losing direction

Mistake 2: Finding transformations without landings, missing cause and effect

Mistake 3: Merging flying stars and natal transformations into one layer

Back to Your Own Chart

The three-step method asks how to read flying stars step by step. Set Tai Ji, find transformations and read landings, and even a complex chart yields a cause-effect line.

Reading Order

  1. Cast the natal chart first and locate the palaces and major stars tied to the three-step flying-palace method before judging anything
  2. Open the triple-direction of those palaces and count the auspicious, malefic and assistant stars separately
  3. Check where the natal Four Transformations land to set the chart's baseline tone
  4. Read the decade-limit transformations to see whether the the three-step flying-palace method line is activated in this stage
  5. Then read the annual transformations and the year's palace to pin down this year's trigger and timing
  6. Layer natal, decade and year before concluding, then decide how to act rather than labeling good or bad
