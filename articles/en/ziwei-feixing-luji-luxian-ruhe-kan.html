How to Trace the Lu and Ji Routes: Linking Cause and Effect Across Palaces

Palace-stem flying transformations link the twelve palaces into a network; Lu is the cause and investment, Ji the result and attachment. Use Lu-turns-to-Ji to trace where the return lands or stalls, setting the Tai Ji first, distinct from static natal transformations.

Zi Wei Dou Shu2026-10-06

Tracing Lu and Ji is like following a chain of transfers to see where money and care went; one palace alone never reveals the other end of cause and effect.

What This Question Is Really Asking

Some read flying stars without setting Tai Ji and lose direction; others inspect one palace without tracing the landing, and end up confusing dynamic flights with static natal transformations.

The Underlying Logic

Palace-stem flights make the twelve palaces a directed relationship network rather than drawers.

Lu governs investment, opportunity and return, Ji governs attachment, debt and sticking points; Lu is the cause and Ji the result.

Lu-turns-to-Ji follows the stem of the palace where Lu lands to see where the benefit finally settles or stalls.

Set Tai Ji before tracing, knowing which palace you speak from, so the direction stays correct.

A Step-by-Step Way to Read It

  1. First settle the matter to trace and the starting palace, setting Tai Ji
  2. Find that palace stem transformations and see where Lu, Quan, Ke and Ji each fly
  3. First read where Lu lands to set the direction of investment and return
  4. Then read where Ji lands to set attachment, debt or the sticking point
  5. Use Lu-turns-to-Ji one more step to see which palace finally holds the result
  6. Conclude within the natal and decade background before deciding how to act

Three Common Mistakes

Mistake 1: Tracing without setting Tai Ji and losing all direction

Mistake 2: Reading one palace without tracing the landing, missing the other end of cause and effect

Mistake 3: Confusing flying transformations with natal transformations and losing the layers

Back to Your Own Chart

Tracing Lu and Ji turns the chart into a cause-and-effect map with a sender and receiver. Set Tai Ji and link the steps one by one, and you learn where a matter returns and where it stalls.

Reading Order

  1. Cast the natal chart first and locate the palaces and major stars tied to tracing the Lu and Ji routes in flying stars before judging anything
  2. Open the triple-direction of those palaces and count the auspicious, malefic and assistant stars separately
  3. Check where the natal Four Transformations land to set the chart's baseline tone
  4. Read the decade-limit transformations to see whether the tracing the Lu and Ji routes in flying stars line is activated in this stage
  5. Then read the annual transformations and the year's palace to pin down this year's trigger and timing
  6. Layer natal, decade and year before concluding, then decide how to act rather than labeling good or bad
