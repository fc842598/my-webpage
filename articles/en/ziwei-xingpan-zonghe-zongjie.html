How to Synthesize the Whole Chart

Synthesis reads palaces, stars, transformations and decade, integrating them into one consistent conclusion: what the main axis is, where the current stage sits, where risks and opportunities are, not scattered statements.

Zi Wei Dou Shu2026-10-08

However detailed single palaces are, without synthesis information is scattered; summary pulls four lines into one statement.

What This Question Is Really Asking

Some read many details but cannot give an overall judgment, lacking synthesis; a good summary lets the reader grasp the main line at once.

The Underlying Logic

Palaces: twelve set each area.

Stars: combinations set expression.

Transformations: set energy switches.

Limits: decade and year set the current stage; four layers as one.

A Step-by-Step Way to Read It

  1. First read all four layers in fixed order
  2. List the main axis and tone
  3. Set the current decade stage theme
  4. Summarize risk (Ji) and opportunity (Lu)
  5. Check whether layer conclusions contradict
  6. Integrate into one consistent summary

Three Common Mistakes

Mistake 1: Piling details without an overall conclusion

Mistake 2: Layer conclusions contradicting without checking

Mistake 3: Summary written as vague praise with no main line

Back to Your Own Chart

Chart synthesis asks how four layers become one consistent judgment. Main axis, stage, risk and opportunity all noted, and the whole chart is complete and clear.

Reading Order

  1. Cast the natal chart first and locate the palaces and major stars tied to synthesizing the whole chart before judging anything
  2. Open the triple-direction of those palaces and count the auspicious, malefic and assistant stars separately
  3. Check where the natal Four Transformations land to set the chart's baseline tone
  4. Read the decade-limit transformations to see whether the synthesizing the whole chart line is activated in this stage
  5. Then read the annual transformations and the year's palace to pin down this year's trigger and timing
  6. Layer natal, decade and year before concluding, then decide how to act rather than labeling good or bad
